# Python Chatbot 🤖

A Python-based chatbot using Natural Language Processing (NLP) and a trained neural network model.

## 📌 Overview

This project is a simple AI chatbot that can understand user messages, classify their intent, and generate an appropriate response.

The chatbot uses a pre-trained neural network model, so users can run the project without training the model again.

## 🚀 Features

- Natural Language Processing (NLP)
- Intent classification
- Neural network-based chatbot
- Pre-trained model included
- Customizable intents and responses
- Simple command-line interface

## 🛠️ Technologies

- Python
- TensorFlow / Keras
- Natural Language Processing (NLP)
- NumPy
- Pickle

## ⚙️ How It Works

The chatbot follows these main steps:

1. The user enters a message.
2. The message is processed using NLP techniques.
3. The input is converted into a numerical representation.
4. The trained neural network predicts the user's intent.
5. The chatbot selects an appropriate response.
6. The response is displayed to the user.

## 🔧 Installation

Clone the repository:

```bash
git clone https://github.com/AminGolami2007/Python_Chatbot.git
```

Navigate to the project directory:

```bash
cd Python_Chatbot
```

Install the required packages:

```bash
pip install -r requirements.txt
```

## ▶️ Usage

Run the chatbot:

```bash
python chatbot.py
```

Then type a message and interact with the chatbot.

## 🧠 Pre-trained Model

The repository includes the trained model:

```text
chatbot_model.h5
```

Therefore, the model does not need to be trained again before running the chatbot.
